# Orchid Gallery SPA – Lab 02 + Slot 9

## Requirements
- Node 21 + Vite 5, OR Node 22.12+ + current Vite

## Install
```bash
npm install
```

## Run
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Core features
- React Bootstrap Navbar
- Orchid cards
- Detail Modal
- Service layer
- Fetch /orchids.json
- Loading / Error / Empty / Data states
- 30-second cache + force reload
